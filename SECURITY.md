# Sicherheit

## Sicherheitslücken melden

Bitte Sicherheitslücken **nicht** als öffentliches Issue melden, sondern über die Funktion „Report a vulnerability“ (GitHub Security Advisories) dieses Repositorys.

Hilfreich sind:
- eine Beschreibung des Problems
- die betroffene Version oder der Commit
- Schritte zum Nachvollziehen

Logs vor dem Anhängen auf Hostnamen, Konten und Token prüfen.

## Unterstützte Versionen

Sicherheitskorrekturen gibt es für die jeweils neueste Version.

Wie RMC mit Anmeldedaten, Zertifikaten und Logs umgeht, beschreibt [docs/sicherheit.md](docs/sicherheit.md).
